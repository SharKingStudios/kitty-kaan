# kitty kaan

*Acceleration controlled cat ears for our FRC driver ;)*

## What is this?

**kitty kaan** is a wearable pair of motorized cat ears designed for our FRC driver. The ears react to acceleration, making them move with the driver in a more expressive way.

The project combines a small electronics stack and compact mounting hardware into a lightweight assembly. An accelerometer detects motion, and the control electronics translate that movement into ear movement. The result is a simple but very silly accessory that gives the driver a pair of responsive “kitty ears.”

This was designed as a small CAD and electronics integration project. A big part of the challenge was packaging everything into the smallest form factor possible while still keeping the assembly buildable. Instead of using one large controller board, the electronics were split across smaller breakout boards so they could fit into tighter spaces and be arranged more flexibly.

## Some context

Its a simpler project for a simple idea.

The goal was to make the electronics stack as small as physically possible, which is why seperate breakouts were used. They also added to the simplicity of the design (which is nice).

Fitting everything together was the hardest part of this mini project, but it turned out looking pretty awesome!
